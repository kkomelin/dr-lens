Ahrefs API key

Ahrefs now requires a free API key for Domain Rating lookups. Getting one takes a minute:

  1. Sign in or create a free account at ahrefs.com.
  2. Generate a key in Account settings → API keys.
  3. Paste it below and save.

The key is stored only on this device (chrome.storage.local) and sent only to api.ahrefs.com with lookup requests.
